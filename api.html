AFFILIATE · 聯盟

媒體聯盟推廣計劃

Spheretap 誠邀香港本地媒體、內容創作者、SEO 網站及社交媒體影響者加入合作夥伴計劃。透過推廣 Spheretap 的內容資源及獎勵資訊，您可以獲得以您的推薦連結帶來的新用戶所產生的佣金收益。

💰
具競爭力的佣金比率
按成功引薦新用戶的數量及質量計算佣金，提供 CPA（每獲取用戶）及 Revenue Share（收益分成）兩種合作模式，靈活配合不同推廣策略。
📊
實時追蹤後台
合作夥伴可登入專屬後台，實時查看點擊數、轉換率、引薦用戶數量及佣金累積情況，數據透明清晰，每日更新。
🎨
豐富推廣素材
提供多種尺寸橫幅廣告（Banner）、文字連結、社交媒體圖片及定制推廣代碼，支援各種推廣渠道及媒體格式。
🤝
專屬夥伴支援
每位合作夥伴均設有專屬聯絡人，提供推廣策略建議、素材製作支援及佣金結算協助，助您最大化推廣效益。

DATA FEED · 資料

即時資料 Feed API

Spheretap 提供 RESTful JSON API，讓合作夥伴網站及應用程式可自動同步最新平台優惠資訊、博客文章及體育新聞。適合需要在自己網站嵌入即時內容的媒體夥伴。

最新博客文章 Feed

GET Request GET https://spheretap.com/data/blog-recent.json // Response Example { "articles": [ { "slug": "bonus-tips", "title": "迎新獎勵攻略2026", "date": "2026-05-27", "category": "優惠資訊", "url": "/blog/bonus-tips" } ] }

體育新聞 Feed

GET Request GET https://spheretap.com/data/sports-recent.json // Response Example { "news": [ { "slug": "2026-05-27-match", "headline": "英超決賽結果", "category": "足球", "date": "2026-05-27" } ] }
🔑 API 存取說明： 公開 Feed（blog-recent.json、sports-recent.json）無需 API Key 即可存取，適合輕量嵌入。如需完整歷史資料、自定義 Webhook 推送或高頻存取（每分鐘超過 60 次請求），請聯絡我們申請合作夥伴 API Key 及簽署使用協議。
1
申請合作夥伴帳號

透過下方聯絡表格提交申請，說明您的網站/應用及使用場景，我們將在 2 個工作天內回覆並提供 API Key。

2
獲取 API Key 及技術文件

收到 API Key 後，可在請求標頭加入 Authorization: Bearer YOUR_API_KEY 進行認證，存取完整 API 端點。

3
整合至您的平台

使用 API 資料自動更新您的網站或應用的內容，可設定定期拉取（建議每 15 至 30 分鐘）或使用 Webhook 模式接收即時推送通知。

Widget 嵌入指南

無需技術背景，只需複製貼上幾行 HTML 代碼，即可在您的網站嵌入 Spheretap 的最新優惠資訊橫幅或文章清單 Widget。

嵌入代碼

HTML Embed Code <!-- Spheretap 優惠 Widget -- 貼到您網頁的 <body> 中 --> <div class="spheretap-widget" data-type="bonus-banner" data-affiliate="YOUR_PARTNER_ID" data-lang="zh-HK"></div> <script src="https://spheretap.com/widget.js" async></script>
⚙️ Widget 客製化選項： data-type 支援 "bonus-banner"（優惠橫幅）、"article-list"（文章清單）、"sports-ticker"（體育新聞跑馬燈）三種類型；data-theme 支援 "light" / "dark" 主題；data-count 可設定顯示條目數量（1-10）。詳細客製化選項請聯絡我們索取完整技術文件。
